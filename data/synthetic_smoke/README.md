# Synthetic smoke-test data (NOT real)

These two files are **synthetic, machine-generated** data used to smoke-test the
pipeline end-to-end:

```
results.csv
goalscorers.csv
```

They contain only 12 invented national teams and random scores. **Do not** treat
them as the real Kaggle dataset.

To experiment with the pipeline using this synthetic data instead of the real
dataset, copy these two files into `data/raw/kaggle_international_results/` and run
the normal workflow.
